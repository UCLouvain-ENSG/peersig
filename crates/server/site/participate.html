Participate

Join in three steps

About three minutes. Nothing leaves your computer or phone before you have seen it, and you can leave at any time from the app.

{{NOTICE}}

  1. Download PeerSig

    macOS

    Apple Silicon Intel
    macOS 12 or newer · Apple Silicon is M1 and newer
    The first time: open the disk image and drag PeerSig to Applications, then open it. macOS says it cannot check the developer: open System Settings → Privacy & Security and choose Open Anyway. PeerSig then installs its capture service, and asks for your password once.

    Windows

    Download for Windows
    Windows 10 and 11 · x64 · .msi installer
    The first time: Windows says it does not know the publisher (the builds are not signed yet): choose More info, then Run anyway. PeerSig then installs its capture service, and Windows asks for an administrator's permission once. Nothing else to install.

    Linux

    .deb .rpm AppImage
    x86_64, with a desktop · .deb for Debian and Ubuntu, .rpm for Fedora, RHEL and openSUSE
    Install with sudo apt install ./PeerSig_*_amd64.deb or sudo dnf install ./PeerSig-*.x86_64.rpm (zypper on openSUSE): the package gives the capture probe the rights it needs. The AppImage runs the app, but cannot give the probe those rights. A server without a desktop: see Linux server.

    Android

    Download for Android
    Android 10 or newer · .apk, not on Google Play
    The first time: open the downloaded file. Android asks whether your browser may install apps: allow it, then choose Install. If Google Play Protect warns about an unknown app, choose More details, then Install anyway. Once you have joined (step 3), choose Allow and start: Android asks once whether PeerSig may set up a VPN.
    A VPN that goes nowhere. On Android, only a VPN app can see which app opens each connection. PeerSig's VPN stays on the phone: it forwards everything unchanged through your usual network, and records only how encrypted connections start, as on a computer. Android runs one VPN at a time: while PeerSig captures, another VPN (the university's, for instance) cannot run. More on Android.

    Linux server

    No desktop needed: the probe and the peersig command, as two system services. The same anonymous weekly ballots as the app; each week's list is reviewed on the command line.

    .deb .rpm
    x86_64 with systemd · .deb for Debian and Ubuntu, .rpm for Fedora, RHEL and openSUSE 
    sudo apt install ./peersig-headless_*_amd64.deb    # Debian, Ubuntu
sudo dnf install ./peersig-headless-*.x86_64.rpm    # Fedora, RHEL
sudo peersig configure     # asks for your code (step 2), then starts
sudo peersig items         # the week's list, before it is sent
sudo peersig status
    Get your code in step 2, then run sudo peersig configure instead of step 3. Each week's list waits a day before it is sent: sudo peersig exclude <id> leaves an item out. More on servers.

  2. Get your code

    Why a code? The collection only accepts ballots from enrolled participants, so that nobody can reach it uncontrolled from the internet and flood it with made-up results (spam). A code lets one computer or phone send at most {{TOKENS}} anonymous ballots a week. It does not identify your ballots: they carry tokens signed blind, which cannot be traced back to the code.
    {{METHODS}}

  3. Open PeerSig and paste it

    The addresses are filled in already: the server {{SERVER}}{{RELAY}}. Paste your code, choose whether to share the server names your non-browser applications connect to, and join.

    Then, every Monday, PeerSig shows you last week's list and waits a day: untick anything you do not want to send. It then sends each item as a separate anonymous ballot. The icon in the menu bar (on Windows, the notification area; on Android, PeerSig's notification) tells you when.

Dedicated observers

Besides participants, the study runs dedicated observers: machines whose traffic may be published, such as lab servers and test computers. Any of the systems above becomes one with an observer code (OBS-…) from the study team, entered in the app or in sudo peersig configure. An observer reports every day, not anonymously, and its items are published as they are, without threshold, apart from the participants'. Their daily table · How they work
