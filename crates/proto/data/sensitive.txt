#   "tor.example.org", not "monitor"; "hallow" not "halloween");
# - several words, the same whole words in a row ("period tracker");
# - a name with a dot, that server name and the names under it
#   ("flo.health" matches "api.flo.health").
# Names are lower-cased, and cut into words at anything not a letter or a
# digit: "com.grindrapp.android" is "com grindrapp android".
